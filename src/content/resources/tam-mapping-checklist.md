The checklist is the file behind the form. It is an example of the shape of the work, not a record of an engagement.

What it asks you to settle before a list gets built:

- Which closed-won deals actually define the vertical, and which were one-off.
- Which firms sit in the market and never appear in the current CRM or on LinkedIn.
- Which firmographics change priority, and which are only descriptive.
- Where the list will live so the CRM and the TAM stay one list.
